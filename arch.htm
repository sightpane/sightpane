Problem: Ingestion logic leaks across HTTP handlers, in-memory rate-limiting maps, SQL privacy rule queries, frame blob writes, and a 550-line transactional item loop.

Solution: Collapse authentication resolution, quota enforcement, payload normalization, privacy scrubbing, frame persistence, and transactional insertion behind one deep intake module.

Wins:
  • • Locality: envelope lifecycle in one module
  • • Leverage: one interface handles all ingest
  • • Tests hit intake without HTTP routing
  • • Quota state stays inside module
  • • Deletes redundant multi-pass JSON parsing
  • • Seam shields handlers from storage transactions

Problem: Authorization is fragmented across route middleware and ad-hoc per-handler checks like sessionAllowed and issueAllowed, risking tenant-isolation leakage if a handler omits the check.

Solution: Enforce tenant and entity scoping through a deep access control module at the routing seam that resolves resource tenancy before handlers execute.

Wins:
  • • Locality: tenant isolation in one seam
  • • Prevents security regressions from missed checks
  • • Handlers receive verified scoped contexts
  • • Eliminates duplicate database lookups in handlers
  • • Interface is uniform across all resources
  • • Tests verify tenancy through single seam
